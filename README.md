Mitti and Masala ☕

A coffee-themed café and dessert shop website built using HTML and CSS.

About the Project

Mitti and Masala is a café-inspired website designed around the warmth of coffee, delicious desserts, and a welcoming café atmosphere.

This project was created as a frontend development practice project to explore webpage design, styling, layouts, and visual presentation.

Technologies Used

- HTML5
- CSS3

Features

- Coffee-themed website design
- Café and dessert shop concept
- Images and visual elements
- Styled webpage layouts

What I Learned

- Structuring webpages with HTML
- Styling layouts using CSS
- Creating a consistent visual theme
- Organizing project files
